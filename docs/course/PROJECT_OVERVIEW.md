# OSS Compass — Electron course project

OSS Compass helps a developer understand public repositories and authorized community context before contributing. The value is informed investigations and follow-through, rather than artificial PR counts.

The application is a real Electron desktop program with a React/TypeScript renderer, sandboxed typed preload boundary, main-process services, SQLite/FTS5 persistence, read-only GitHub API access, native import/export dialogs, and local contribution planning. No backend account or mandatory AI key is required.

The MVP includes issue/PR workspaces, explainable recommendations, manual community notes when integrations are prohibited, transcript and chat-export import, change briefings, private reviews, a journey board, and persistent deterministic conversations. The full vision remains in the original master brief; optional consent-gated OpenAI is implemented; future community adapters remain outside the submission.
