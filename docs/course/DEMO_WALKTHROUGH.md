# Demonstration walkthrough

Allow 10–15 minutes. Use a separate demo data directory if the normal profile contains private imports.

1. Run `npm ci`, then `npm run dev`. Explain the main, preload and renderer processes using the architecture diagram.
2. Complete onboarding with a username, React/TypeScript skills, five-hour capacity and contribution goal.
3. Open Repositories. Add a public repository and synchronize. Point out cached timestamps, partial coverage and API limits. A network failure is an honest cached-data state, not a reason to claim success.
4. Load the synthetic demo workspace for repeatable examples. Point out the amber demo marker. This fixture is fictional.
5. Open Opportunity Radar, inspect #42, read Before You Start and coverage, save it and write a private investigation note. Inspect #57 and explain the related-PR warning.
6. Open PR Review Queue, inspect #71 and set Needs follow-up. Save a note, click Record inspection and expand Inspection history. Explain unknown/stale observation times and that nothing is posted to GitHub. Real records can open their public diff.
7. Open Community Context → Capture context. Acknowledge permission and choose `tests/fixtures/meeting.vtt` through the native file dialog. Inspect the timestamped transcript and explicit #42 link.
8. Highlight a passage, classify it as an action and add a note. Search for redraw. Create a separate manual note and point out its unverified provenance. Explain that no Slack workspace integration is needed or attempted.
9. Return to Overview: the imported reference appears in the briefing, and the saved investigation persists.
10. Open My Journey. Add a realistic objective with hours and a custom deadline. Try exceeding capacity to demonstrate validation. Export a factual Markdown report and inspect the manual/private distinctions.
11. Open AI Copilot and a synthetic example. Then create a real local conversation, select an issue, and send a question. Explain the deterministic label and that no model or external upload occurred. Rename, search and export it.
12. Restart Electron. Verify profile, saved note, private review, import and real conversation persist.
13. Switch to light theme. Hide demo data; show that synthetic example conversations disappear while real local conversations remain.
14. Show `npm run typecheck`, `npm run lint`, `npm test`, and `npm run test:e2e` results. Remember native ABI switching before restarting Electron.
15. Show actual commits with `git log --format=fuller`, tags, the dated journal, original prompt, AI disclosure and generated milestone report.
16. Launch the available packaged application. Explain that Windows NSIS configuration exists but Windows runtime certification/signing are separate from the macOS build.

No screenshots or synthetic conversation content should be presented as historical maintainer interactions or live model output.
